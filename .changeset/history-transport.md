The archive becomes browsable: window/period-parameterized history with fetcher injection. New `StationHistory` document (`{ schemaVersion, servedAt, stationId, history }`, reusing the history shape — `periodMinutes` echoes what the source actually supplied) with its own schema artifact. `loadWindnerdHistory(config, { fromMs, toMs, periodMinutes })` fetches whole UTC days so every zoom over the same day reuses one cache entry (fully-past windows cache ~30 days) and slices back to the request; fleet-level `loadStationHistory` dispatches by station id (`StationHistoryUnsupportedError` for vendors without an archive). The handler serves `GET /history?station=&from=&to=&period=` — 400 on a bad window, an unservable period, or a window over the point budget; fully-past responses cache a day with the usual ETag/304. `historyEndpoint` builds the URL; on the client, `StationHistoryFetcher` is the archive components' data contract — `stationHistoryFetcher(base, stationId)` is the handler-backed default, and `createStationHistoryStore(fetcher)` wraps any implementation in a window-keyed LRU that dedupes in-flight windows and never caches a failure. A host that serves history through its own authenticated function supplies the fetcher and never touches the handler.
