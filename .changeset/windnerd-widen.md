"@azohra/meteo.station": minor

The WindNerd adapter reads the fields it previously discarded, all additive; schemaVersion stays 2. `StationMeta` gains nullish `declaredFavorableDirections` (the source's declared sectors, adoptable via the new `declaredFavorableDirections(station)` helper, never applied as a judgment default; null = nothing knowable, `[]` = explicitly none) and `broadcastDelaySeconds`. `HistoryPoint` gains nullish `windVectorAvgMps`, `temperatureMinC`/`temperatureMaxC`, and `seaLevelPressureMinHpa`/`seaLevelPressureMaxHpa`. The adapter parses the live INIT frame's location block (`parseWindnerdLiveLocation`, exported with `windnerdEnrichedMeta` and `parseStandardTimeOffset`): dir_ranges, altitude, timezone, position, standard offset, and broadcast delay enrich the meta with config-wins precedence, in full mode through a 6-hour `windnerd/location/<id>` cache so feed polls never pay a live connection. `WINDNERD_RECORD_PERIODS_MINUTES` widens to the verified vendor catalogue `[1, 5, 10, 15, 30, 60, 180, 360]`. Records parsing reads `wind_avg_2D` and the optional temperature/pressure spreads; the retired `time_offset` column parsing is deleted (exported `WindnerdRecords` loses `utcOffsetMinutes`; the standard offset now rides `WindnerdLiveLocation.standardUtcOffsetMinutes`). Dead `STATION_WIRE_V1_RENAMES` is removed (never exported).
